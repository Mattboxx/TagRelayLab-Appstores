# TagRelayLab Server 1.1.39

- Google Raw opens with the most recently received reports. Each entry shows
  when the position was observed and when TagRelayLab received the report.
  Older observations can still be received today; raw records are unchanged.
- Google refresh shows completed and total trackers and saves results for
  each tracker as soon as its response arrives. It does not send concurrent
  requests to the shared Google listener.

Update using the [installation guide](INSTALLATION.md) and keep your existing
volumes. No tracker, credential or firmware changes are needed.
