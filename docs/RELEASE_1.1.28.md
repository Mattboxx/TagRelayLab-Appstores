# TagRelayLab Server 1.1.28

## Map and mobile controls

- The neutral translucent map panels use a local Liquid Glass-style treatment.
  The active source and history selector has a moving highlight.
- The lower-left mobile button opens the devices drawer with a larger SVG icon.
  The drawer slides up and closes faster; reduced-motion preferences are respected.
- Account, visibility, device settings and reorder controls use consistent icons
  and larger mobile touch targets. The separate top map toolbar remains collapsible.

## History and saved devices

- Fetch saved history in pages across the chosen date range, including older
  positions beyond the first response. The map remains usable while history loads.
- Retain Latest as the startup mode and remember the account's default map source
  (All, Apple, or Google). No report is changed by selecting a range.

## Updating

Back up your data, then update to 1.1.28 with your existing Compose project and
volumes. Reload the browser tab afterwards. Existing accounts, identities,
locations and firmware are preserved. Anisette remains separate from the bundle;
standard compatible providers are still supported.

and [licensing and sources](LICENSING.md). The images use synthetic demonstration data.
